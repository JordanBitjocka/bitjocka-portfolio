# Bitjocka IV — Portfolio

A React and TypeScript portfolio presenting practical machine-learning prototypes, structured backend work, web applications, mobile interfaces, and a developing cybersecurity practice.

## Built with

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- Lucide React
- Wouter
- Framer Motion utilities

## Featured work

- **WellBot** — a Python/Flask machine-learning prototype using a Decision Tree workflow for informational symptom guidance.
- **INTERSTATION Backend** — a company backend project organized around authentication, users, categories, credentials, interests, and test-related flows.
- **School Management System** — a Django web application concept for enrollment, attendance, grades, and communication.
- **Stock Management App** — a Flutter mobile interface for stock-management workflows.

## Local development

```bash
pnpm install
pnpm dev
```

To create a production build:

```bash
pnpm build
```

## Notes

This repository contains the portfolio presentation layer. Project descriptions are intentionally evidence-led and distinguish public source code from private company work. The INTERSTATION repository remains private.
